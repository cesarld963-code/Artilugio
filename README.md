# Artilugio
habilidad **`iah-bot-codec`** basada en la configuración y el script de Streamlit para el proyecto autonomo **Sabiduria-IAH**.  Esta nueva habilidad incorpora:  * La lógica del cifrado de la matriz 6x6. * Las funciones de codificación de texto a tramas binarias. * La estructura del entorno de Streamlit con su panel de control en modo oscuro.
